# FSRS-5 Stage 1 (opt-in)

Tlahtōlli retains its established classic scheduler by default and offers an offline FSRS-5 option in the study panel. Target retention is configurable separately for vocabulary, reverse cards and verb paradigms (80–97%). Switching schedulers **does not** modify due dates until a card is graded. Review history, Undo, practice-only mode, existing limits, leeched/suspended flags, Anki TSV export and full JSON backups are retained. Personal browser data is never uploaded to this repository.

Historical classic reviews without model state receive conservative inferred FSRS memory estimates at the next grading; no fabricated rating history is created. FSRS-5 scheduling uses fixed published weights with a short-term step handler; it should not be represented as byte-for-byte parity with current Anki. Exporting an Anki TSV does not transfer this app's schedule.
